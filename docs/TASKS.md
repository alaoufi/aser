## المتبقي قبل فتح التسجيل الإنتاجي

- [ ] مزود SMS حقيقي واختبار وصول OTP لرقم معتمد؛ لم يُعط مزود أو رقم اختبار.
- [ ] إنشاء أول حساب إدارة من مستخدم تحقق فعليًا؛ لا توجد حسابات افتراضية.
- [ ] رحلة أسرة حقيقية كاملة من الجوال بعد تفعيل الخدمات، دون اعتبار mocks إثبات SMS.
- [ ] رفع شعار وغلاف الأسرة والفيديو الاختياري وQR؛ لم تُنفذ واجهات رفعها بعد.
- [ ] نسخة خارج الخادم ومفتاح استعادة محفوظ بصورة مستقلة؛ تتطلب وجهة مناسبة.
- [ ] مراقبة سعة وحدتي التخزين وفشل النسخ، وتنبيهات إلى وجهة يعتمدها المستخدم.
- [x] توجيه DNS وHTTPS وتحويل www؛ حلت المنصة العامة محل صفحة الإنشاء.
- [ ] لاحقًا: الطلبات والمفضلة والإشعارات والتقييمات ثم Android وiOS.

لا تغيّر حجم وحدات التخزين أو قاعدة أي خدمة، ولا تنظف Docker أو مساحة الخادم
العامة ضمن مهام هذا المشروع. أي توسيع يحتاج قياس المساحة ونسخة استعادة أولًا.
