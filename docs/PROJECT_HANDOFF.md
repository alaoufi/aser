التطبيق أو نشره للعامة. استُبعد Neon بناء على توجيه المستخدم؛ PostgreSQL محلي
داخل Docker هو الخيار المعتمد.

- مسار التشغيل `/opt/jdatna`، مشروع Compose باسم `jdatna`.

- شبكة `jdatna_database` داخلية، لا منافذ منشورة ولا اتصال بشبكات أي خدمة.

- `python3 /opt/jdatna/infra/verify.py`: نجحت اختبارات العزل والمصادقة وصلاحيات CRUD
  داخل معاملة جرى التراجع عنها؛ لا سجلات تجريبية باقية.

- حاويات `aykdmh-web/app/db/livekit` احتفظت بمعرفاتها وأوقات بدء التشغيل.
- SHA256 لملف Compose وملفات Caddy الخاصة بأي خدمة لم يتغير.
- `https://aykdmh.com` استجاب HTTP 200 بعد التجهيز.
- `systemd-analyze verify` لوحدات المشروع: نجح.
- أُعيد تشغيل **خدمة jdatna فقط** للتحقق من استمرار التشغيل؛ لم يُعد تشغيل الخادم.
