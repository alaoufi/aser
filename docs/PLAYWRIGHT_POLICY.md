# سياسة الاختبار بـ Playwright (قرار المالك 2026-11-25)

Microsoft Playwright (https://github.com/microsoft/playwright) أداة الاختبار الأساسية والدائمة.

## الأدوات

- **Playwright Test** (`@playwright/test`): اختبارات المتصفح في `tests/e2e/`، وتعمل في GitHub Actions مع كل تحديث.
- **Playwright MCP** (`.mcp.json` ← `scripts/playwright-mcp.cjs`، الإصدار `@playwright/mcp@0.0.86`): يتحكم به Claude بالمتصفح مباشرة لفحص الصفحات والنقر والقراءة وقياس الطلبات.

## متى يُستعمل (تلقائيًا، بلا طلب)

بعد كل تعديل برمجي أو تصميمي يمس الواجهة: صفحة، نموذج، فلتر، بحث، تصنيف، تنقل، أو شكل.

## ماذا يُختبر

1. **الفلاتر والبحث والتصنيفات** ودقة النتائج **مطابقةً لقاعدة البيانات**: ما يُعرض للمستخدم بالضبط، لا استجابة الأزرار فقط (لا نقص، لا زيادة، لا تكرار).
2. **كل التركيبات الممكنة عمليًا** للفلاتر المترابطة والمتداخلة: كل فلتر منفردًا، وكل زوج، وتركيبات أعمق مختارة، والتسلسل الهرمي (القسم الأب يشمل أبناءه).
3. **الترقيم** والتحميل التدريجي: كل المطابق يصل، بلا تكرار بين الصفحات.
4. **السرعة وتعارض الطلبات**: زمن كل استعلام وصفحة، والتبديل السريع المتكرر ينتهي بنتيجة آخر اختيار.
5. **الأجهزة**: الكمبيوتر والجوال والتابلت.

## القواعد

- الاختبارات محفوظة في المستودع: `tests/e2e/*.spec.ts` للمتصفح، و`tests/*.test.ts` لقاعدة البيانات.
- تعمل تلقائيًا في GitHub Actions (`.github/workflows/ci.yml`)، ومنها مهمة «اختبارات قاعدة البيانات والفلاتر» بقاعدة PostgreSQL مؤقتة.
- **لا بيانات إنتاج في أي اختبار يكتب أو يعدّل أو يحذف**: قاعدة اختبار اسمها يبدأ بـ `jdatna_test_`، يتحقق كل اختبار منها قبل الكتابة، ويحذف بياناته بعده. على الموقع الحي: قراءة فقط.
- خطأ مكتشف يُصلح من سببه الجذري، ثم تُعاد الاختبارات، وتُسجَّل النتيجة في `docs/DECISIONS.md`، ويُبلَّغ المالك بالنتائج الحقيقية فقط.
- يُثبَّت إصدار الأداة ولا يُرفع إلا باختبار.

## التشغيل

- محليًا: `npx playwright test` (أو ملف واحد: `npx playwright test tests/e2e/filters.spec.ts`).
- اختبارات قاعدة البيانات: `JDATNA_TEST_DB=true npm test` على قاعدة اختبار.
