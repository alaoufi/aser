# «مكتبة الموائد» — أشكال مائدة الأسرة للاعتماد (لم يُبنَ الاختيار بعد)

فكرة المالك: كل أسرة لها مائدتها في صفحتها، وعليها أطباقها الجاهزة اليوم، واسمها مكتوب بخط عربي جميل لا يتداخل مع الأطباق.

النماذج أربعة أشكال على 390، والمقارنة في `tables-compare.png`. كلها CSS وSVG خفيفة بلا صور إضافية، والأطباق من `public/food`. الاسم «مطبخ أم سالم» والأسعار توضيحية؛ عند التنفيذ يُكتب اسم الأسرة من بياناتها.

| الشكل | الصورة | الفكرة |
|---|---|---|
| **السدو** (الافتراضي) | `table-sadu-390.webp` | مفرش سدو عريض، والاسم على شريط بحافتي سدو. هو المنفّذ الآن في #148. |
| **المفرش الأبيض** | `table-abyad-390.webp` | قماش أبيض بنسيج ناعم وغرزة حمراء متقطعة وحافة مخرّمة، والاسم مطرّز بالأحمر. |
| **صينية النحاس** | `table-nahas-390.webp` | صينية مستديرة بحلقات منقوشة، والاسم على لوحة نحاسية، والنصوص على خلفية فاتحة لتبقى مقروءة. |
| **سفرة الخوص** | `table-khoos-390.webp` | حصير نخل مجدول بخطوط حمراء وزيتونية خلف الصحون فقط، والاسم على بطاقة دائرية بإطار خوص. |

## بعد اعتماد المالك (لم يُنفَّذ)
- **لوحة الأسرة:** «اختاري مائدتك» مع معاينة حية قبل الحفظ، والافتراضي السدو.
- **الإدارة:** تضيف الأشكال وتخفيها وتسمّيها.
- **النصوص:** كل نص (أسماء الأشكال، العناوين، الأزرار) في «نصوص الموقع».
- **الخط:** الاسم بخط Amiri المعتمد.

## إعادة الرسم
`cd src && node render.cjs`، مع `PW_CHROMIUM_PATH` إن لزم.
