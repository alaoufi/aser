# مشروع: أكلات وغذاء الأجداد
## بناء موقع إلكتروني وتطبيقات Android وiOS للأسر المنتجة

### 1. الهدف العام

إنشاء منصة سعودية احترافية باسم **«أكلات وغذاء الأجداد»**، متخصصة حصريًا في عرض وتسويق الأطعمة والمأكولات والمنتجات الغذائية التي تقدمها الأسر المنتجة.

المنصة تربط الأسر المنتجة بالمستهلكين بشكل مباشر، وتساعد على حفظ الأكلات التراثية والشعبية والتعريف بها.

**السياسات الأساسية:**
- يمنع تسجيل المطاعم والشركات التجارية غير المؤهلة ضمن فئة الأسر المنتجة.
- التسجيل مجاني مبدئيًا للأسر والعملاء.
- لا تفرض المنصة عمولة أو اشتراكًا إلا بقرار صريح من الإدارة مستقبلًا.
- لا يشترط الدفع الإلكتروني.
- التواصل والطلب مباشرة مع الأسرة المنتجة أو عبر نظام طلبات المنصة.
- واجهة عربية بالكامل RTL، مع قابلية إضافة لغات لاحقًا.
- الموقع والتطبيقات مرتبطة بقاعدة بيانات موحدة.
- إعطاء الأولوية للبساطة والسرعة وسهولة الاستخدام على الجوال.

### 2. أنواع المستخدمين

**أولًا: الزائر والعميل**
- تصفح الأسر والمنتجات دون تسجيل.
- البحث حسب المنطقة والمدينة والحي.
- استعراض المنتجات والأسعار وطرق الاستلام.
- الاتصال أو التواصل عبر واتساب.
- إضافة المنتجات للمفضلة.
- إرسال طلب للأسرة المنتجة.
- متابعة حالة الطلب في حال استخدام نظام الطلبات.
- تقييم الطلب بعد اكتماله.

**ثانيًا: الأسرة المنتجة**
- إنشاء حساب.
- تسجيل البيانات والمستندات.
- إدارة الصفحة التجارية.
- إضافة وتعديل المنتجات.
- استقبال الطلبات.
- تحديد مواعيد العمل والتجهيز.
- إدارة التوصيل والاستلام.
- متابعة التقييمات والإحصائيات.

**ثالثًا: الإدارة**
- مراجعة وتفعيل الأسر المنتجة.
- قبول أو رفض أو تعليق الحسابات.
- إدارة الاستثناءات.
- الإشراف على المنتجات والتصنيفات.
- إدارة البلاغات والشكاوى.
- التحكم في ظهور وتوثيق الحسابات.
- إدارة المحتوى والإعلانات والسياسات.

### 3. تسجيل الأسر المنتجة

إنشاء نموذج تسجيل بسيط ومتدرج.

**أ. إثبات أهلية التسجيل**

تختار الأسرة إحدى الوسائل التالية:

1. سجل تجاري ساري ومناسب للنشاط.
2. وثيقة عمل حر مناسبة للنشاط.
3. شهادة تسجيل أسرة منتجة.
4. الهوية الوطنية للمراجعة والتحقق الإداري، دون اعتبارها ترخيصًا لمزاولة النشاط.
5. استثناء إداري، يخضع للمراجعة والتأكد من استيفاء المتطلبات النظامية اللازمة قبل السماح بالبيع.

البيانات المطلوبة:
- نوع المستند.
- رقم المستند إن وجد.
- رفع صورة أو ملف المستند.
- تاريخ انتهاء المستند إن وجد.
- اسم صاحب الحساب.
- رقم الجوال مع التحقق برمز OTP.

يجب حفظ المستندات بصورة مشفرة وخاصة، ولا تظهر للزوار.

**ب. بيانات الأسرة التجارية**

- الاسم التجاري أو اسم الأسرة المنتجة (إجباري).
- صورة الشعار (اختياري).
- صورة الغلاف (اختياري).
- وصف مختصر عن الأسرة (اختياري).
- المنطقة (إجباري).
- المدينة (إجباري).
- الحي (اختياري).
- الموقع الجغرافي على الخريطة (اختياري، وخاص حتى تسمح الأسرة بمشاركته).
- الموقع الإلكتروني (اختياري).
- نوع المنتجات المقدمة (إجباري، متعدد الاختيارات).
- رقم الجوال (إجباري).
- رقم واتساب (اختياري، ويمكن استخدام نفس الجوال).

**ج. وسائل التواصل الاجتماعي**

جميعها اختيارية:
- TikTok.
- Snapchat.
- Instagram.
- X / Twitter.
- Telegram.
- الموقع الإلكتروني.

يتم التحقق من صحة الروابط وإظهار أيقونات المنصات مع إمكانية فتحها مباشرة.

### 4. خيارات التوصيل والاستلام

عند تسجيل الأسرة، يظهر السؤال:

**هل توفر الأسرة خدمة التوصيل؟**
- نعم.
- لا.

عند اختيار نعم:
- تحديد المدن والأحياء المشمولة بالتوصيل.
- رسوم التوصيل أو التوصيل المجاني.
- الحد الأدنى للطلب (اختياري).
- مدة التوصيل المتوقعة.
- إمكانية الاتفاق على التوصيل مع العميل.
- السماح باستلام الطلب دون توصيل.

عند اختيار لا:
- تحديد هل الاستلام متاح من موقع الأسرة أو نقطة استلام خارجية.
- تحديد موقع الاستلام على الخريطة.
- عدم إظهار عنوان السكن الخاص علنًا.
- إظهار نقطة الاستلام الدقيقة فقط للعميل صاحب الطلب وبعد موافقة الأسرة.

**عند طلب العميل:**
- توصيل إلى العميل.
- استلام شخصي.
- اتفاق مباشر مع الأسرة.

إذا اختار العميل عدم التوصيل، يظهر له موقع الاستلام المسموح بمشاركته ورابط الاتجاهات في الخرائط.

إذا كانت الأسرة لا توفر التوصيل، لا يظهر خيار التوصيل في الطلب.

### 5. إضافة المنتجات

كل أسرة تستطيع إضافة عدد من المنتجات وإدارتها.

**بيانات المنتج:**

- اسم المنتج: إجباري.
- نوع المنتج: اختياري.
- تفاصيل المنتج: إجباري.
- مكونات المنتج: اختياري عمومًا، مع تطبيق متطلبات الإفصاح الغذائي اللازمة.
- السعر: أحد الخيارين:
  - سعر محدد بالريال السعودي.
  - السعر عند التواصل.
- كمية المنتج أو وزنه: اختياري.
- وحدة البيع: حبة، طبق، كيلو، نصف كيلو، علبة، صينية، كرتون، أو وحدة مخصصة.
- صور المنتج: اختياري.
- فيديو قصير: اختياري.
- حالة المنتج: متوفر، غير متوفر، حسب الطلب.
- وقت التجهيز المتوقع: اختياري.
- الحد الأدنى للطلب: اختياري.
- عدد الطلبات الممكن تجهيزها يوميًا: اختياري.

**خيارات الدفع:**
- نقدًا عند الاستلام.
- تحويل بنكي.
- خيار دعم الدفع الإلكتروني مستقبلًا، دون تفعيله الآن.

عند التحويل البنكي:
- اسم صاحب الحساب.
- اسم البنك.
- رقم الآيبان IBAN.
- إمكانية إظهار تعليمات التحويل للعميل بعد تأكيد الطلب.
- عدم تخزين بيانات بطاقات بنكية.
- إمكانية إرفاق إثبات التحويل بصورة خاصة ضمن الطلب.
- تأكيد استلام المبلغ من الأسرة.

**ملاحظة:** لا يظهر زر دفع مباشر إذا اختير «السعر عند التواصل»، وإنما زر «استفسر عن السعر» أو «اطلب عرض سعر».

- اختيار المنطقة والمدينة.

- تصفح حسب نوع الأكلة.

### 9. نظام الطلبات

توفير طريقتين حسب إعداد الأسرة:

**الطريقة الأولى: الطلب عبر التواصل**
- الاتصال.
- واتساب.
- طلب عرض سعر.

**الطريقة الثانية: طلب داخل المنصة**

يسمح للعميل باختيار:
- المنتج.
- الكمية.
- الملاحظات.
- موعد الاستلام أو التوصيل.
- طريقة الاستلام.
- طريقة الدفع.
- بيانات التواصل اللازمة.

حالات الطلب:
1. طلب جديد.
2. بانتظار قبول الأسرة.
3. مقبول.
4. قيد التجهيز.
5. جاهز للاستلام.
6. خرج للتوصيل، إن وجد.
7. مكتمل.
8. ملغي أو مرفوض مع السبب.

يرسل النظام إشعارات للأطراف عند كل تغيير مهم.

لا يفترض النظام تنفيذ الدفع أو استلام الأموال بواسطة المنصة ما لم يُفعّل ذلك مستقبلًا.

### 10. المزايا الإضافية المقترحة

**أ. الطلب المسبق**
تستطيع الأسرة تحديد أن المنتج يحتاج إلى الحجز قبل يوم أو أكثر.

**ب. الأكلات الموسمية**
إظهار المنتجات المتاحة في رمضان والأعياد والشتاء والمناسبات.

**ج. إشعار العودة للتوفر**
إذا أصبح المنتج متوفرًا، يمكن إشعار العملاء المهتمين.

**د. المفضلة**
حفظ الأسر والمنتجات للرجوع إليها.

**هـ. التقييمات**
السماح بالتقييم بعد الطلب المكتمل، مع منع التقييمات الوهمية والإساءة.

**و. مشاركة المنتجات**
مشاركة المنتج مباشرة عبر واتساب أو روابط التواصل.

**ز. العروض**
تستطيع الأسرة إضافة عرض مؤقت وتحديد تاريخ بدايته ونهايته.

**ح. المنتجات حسب المناسبة**
طلبات العزائم والولائم والضيافة والمناسبات العائلية.

**ط. البحث الذكي**
البحث باسم الأكلة أو مكوناتها أو اسم الأسرة أو المدينة، مع دعم الأخطاء الإملائية والأسماء المحلية المختلفة.

**ي. أوقات العمل**
تحديد أيام استقبال الطلبات ومواعيد تجهيزها والتوقف المؤقت.

**ك. دعم كبار السن**
واجهة سهلة بخط واضح وأزرار كبيرة ونماذج قصيرة.

**ل. قصة الأكلة**
حقل اختياري يعرض أصل الأكلة وطريقتها التراثية وقصتها، دون كشف وصفة الأسرة الخاصة.

### 11. سلامة الغذاء وحماية المستهلك

هذه متطلبات مهمة للمنتجات الغذائية:

- مراجعة أهلية الأسرة لمزاولة النشاط الغذائي وفق التنظيمات السارية.
- السماح بتسجيل بيانات شهادات أو تصاريح السلامة المطلوبة بحسب النشاط.
- إظهار مسببات الحساسية الرئيسية عند انطباقها.
- تحديد مدة الصلاحية وشروط الحفظ للمنتجات التي تستدعي ذلك.
- تحديد متطلبات التبريد أو النقل الحراري.
- منع المنتجات الغذائية غير الآمنة أو المخالفة.
- إضافة سياسة واضحة للشكاوى والاسترجاع.
- عدم إظهار علامة «موثقة» إلا وفق معايير واضحة ومعتمدة.
- إدارة البلاغات وسحب المنتجات المخالفة.
- منع نشر رقم الهوية أو المستندات أو عنوان السكن أو المعلومات الحساسة.

موافقة الإدارة على الحساب لا تعني إصدار ترخيص حكومي.

### 12. لوحة تحكم الإدارة

إنشاء لوحة إدارية متكاملة تتضمن:

**إدارة الأسر**
- قائمة الأسر المسجلة.
- طلبات التفعيل الجديدة.
- مراجعة المستندات.
- اعتماد أو رفض التسجيل مع السبب.
- تعليق وإعادة تنشيط الحساب.
- سجل قرارات التوثيق.
- إدارة الاستثناءات مع توثيق سببها.

**إدارة المنتجات**
- استعراض المنتجات.
- تعديل التصنيفات.
- إخفاء المنتجات المخالفة.
- إدارة البلاغات.
- تحديد المنتجات المميزة.

**إدارة المناطق**
- المناطق.
- المحافظات إن احتاجها التسلسل الإداري.
- المدن.
- الأحياء.

يجب ربط المدينة بمنطقتها وربط الحي بالمدينة ومنع التكرار.

**الإحصائيات**
- عدد الأسر المسجلة.
- عدد الأسر المعتمدة.
- عدد المنتجات.
- عدد الطلبات المسجلة داخل المنصة.
- أكثر المنتجات زيارة.
- أكثر المدن نشاطًا.
- عدد الزيارات وطلبات التواصل.

لا تسجل عمليات الاتصال أو واتساب على أنها مبيعات مكتملة دون تأكيد موثوق.

**إدارة الإعلانات**
- إعلانات المنصة.
- المنتجات المميزة.
- إعلانات المناسبات.
- إبراز أسر معينة وفق ضوابط عادلة.

### 17. تعليمات التنفيذ الإلزامية

- ابدأ بفحص أي مشروع أو قاعدة بيانات موجودة قبل التعديل.
- لا تحذف بيانات أو ملفات أو وظائف قائمة.
- أنشئ الجداول الناقصة فقط.
- تجنب تكرار الوظائف والمكونات.
- افصل صلاحيات الإدارة والأسرة والعميل.
- لا تستخدم بيانات وهمية في الإنتاج.
- اختبر التسجيل والبحث والطلبات والروابط والخرائط.
- اعتمد حماية بيانات الهوية والاتصال والمعاملات.
- لا تعتبر الاستثناء الإداري بديلًا عن أي ترخيص إلزامي.
- وثّق كل مرحلة من التطوير.
- احفظ التعديلات في Git مع رسائل Commit واضحة.
- لا ترفع كلمات المرور والمفاتيح السرية إلى المستودع.
- لا تعلن اكتمال وظيفة قبل اختبارها.
- قدّم تقريرًا بما تم تنفيذه وما تبقى والأخطاء والمخاطر.

**النتيجة المطلوبة:**
منصة متكاملة وسهلة الاستخدام تحفظ هوية المأكولات التراثية وتمنح الأسر المنتجة حضورًا رقميًا احترافيًا، وتسمح للمستهلك بالوصول إلى الأطعمة المنزلية المحلية والتواصل أو الطلب منها بوضوح وأمان، دون تعقيد أو رسوم غير ضرورية.
