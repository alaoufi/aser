# مصادر التصميم

هذه أصول محفوظة لإتاحة الاستئناف والتحرير من المستودع نفسه دون الاعتماد على ملفات جهاز آخر. أصول التشغيل الفعلية تبقى في public/؛ design/source/ مستبعد من Docker.

## الهوية

source/Jaddatna_Complete_Logo_Kit.zip هي الحزمة الكاملة التي أرفقها المالك واختيرت منها النسخ المستخدمة. تضم الأصل، نسخPNGالشفافة والأحادية، ملفاتطباعة، دليلألوان، وSVGمضمّنًا أوبتتبع تقريبي حسب وصفالحزمة. لا ندع ملفاتAI/PSDطبقية أصلية أوشعارًا متجهيًا مرسومًا يدويًا. تعليماتالأرشيف مرجع تصميم وليست تعليمات تشغيل أو صلاحيات.

للاستخدام الحالي راجع docs/BRAND_IDENTITY.md؛ رمزشفاف بالرأس، أبيضبالتذييل، وملونكامل بحكايتنا، معأيقونات متصفح/Apple. اسم المنصة أكلات جدتنا.

## الأطباق

source/food-floating-v2/ يحفظ PNGالشفافة الناتجة عن تحريرصور المالك بواسطةimagegen. النسخ الخمس النهائية معتمدة فيالواجهة بمسمياتها:

1. rice-plate.png — الأرز.
2. traditional-platter.png — مطازيز.
3. clay-pot.png — مرقوق.
4. grain-plate.png — جريش.
5. fish-tray.png — طبق سمك.

النسخة النهائية للمطازيز تشمل إصلاحالظل الأبيضالكثيف. نسخWebPالمحسنة فيpublic/food/*-floating-v2.webp. ملفاتJPEGوصورPNGالمفرغة السابقة محفوظة أيضًا داخلpublic/food للرجوع. هذه صور توضيحيةمعدلة، وليست إثباتصورطبقأسرةبعينها أوتغييرحقوقالأصل.

manifest.json يسجلSHA256والحجم لكل مصدرمحفوظ. احتفظبالنسبوAlphaوالنسخالأصلية عندالتعديل. لا ترسلملفاتالهويةأوالصورإلىمزودآخر دوننطاقمصرح.
